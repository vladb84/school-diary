# Школьный дневник

Семейный планировщик учёбы для детей с родительским контролем.

## Возможности
- Несколько профилей детей (с годом рождения и классом)
- Календарное расписание: еженедельный шаблон + разовые уроки
- Домашние задания привязаны к предметам из расписания
- Оценки с подсчётом среднего балла
- Кружки и секции
- Режим родителя по PIN-коду
- Данные сохраняются в localStorage

## Стек
React 18 + Vite + Tailwind CSS

## Запуск
```bash
npm install
npm run dev
```
